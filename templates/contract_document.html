สำเนาบัตรประจำตัวประชาชนของผู้เช่าซื้อ

[ พื้นสำหรับวางสำเนาบัตรประชาชน หรือแนบเอกสาร ]

สัญญาฉบับนี้ทำขึ้นระหว่าง ร้านบริการผ่อนสินค้ามือถือ (ซึ่งต่อไปในสัญญานี้จะเรียกว่า "ผู้ให้เช่าซื้อ") ฝ่ายหนึ่ง กับ {{ c.customer_name }} เลขประจำตัวประชาชน {{ c.id_card if c.id_card else '-' }} เบอร์โทรศัพท์ {{ c.phone }} (ซึ่งต่อไปในสัญญานี้จะเรียกว่า "ผู้เช่าซื้อ") อีกฝ่ายหนึ่ง ทั้งสองฝ่ายตกลงทำสัญญากันมีข้อความดังต่อไปนี้:

ข้อ 1. สินค้าเช่าซื้อ: ผู้ให้เช่าซื้อตกลงให้เช่าซื้อ และผู้เช่าซื้อตกลงเช่าซื้อโทรศัพท์มือถือ/สินค้า {{ c.product_name }} หมายเลขเครื่อง (IMEI): {{ c.imei if c.imei else '-' }}, หมายเลขซีเรียล (Serial No.): {{ c.serial_number if c.serial_number else '-' }}, สี: {{ c.color if c.color else '-' }}, ความจุ: {{ c.capacity if c.capacity else '-' }}

ข้อ 2. ราคาสินค้าและการชำระเงิน: ผู้เช่าซื้อตกลงชำระเงินค่าเช่าซื้อเป็นจำนวนเงินรวมทั้งสิ้น ฿{{ "{:,.2f}".format(c.total_amount) }} บาท โดยแบ่งชำระเป็นรายเดือน รวมทั้งสิ้น {{ c.total_installments }} งวด งวดละ ฿{{ "{:,.2f}".format(c.installment_amount) }} บาท กำหนดชำระทุกวันที่ {{ c.due_day if c.due_day else 5 }} ของทุกเดือน ผู้เช่าซื้อชำระล่าช้าเกินกำหนดได้สูงสุด 2 วันโดยไม่ถูกปรับ หากผู้เช่าซื้อชำระล่าช้าเกินกว่า 2 วัน ผู้เช่าซื้อตกลงที่จะชำระค่าปรับเป็นจำนวน 100 บาท ต่อวันตามจำนวนวันที่ผู้เช่าได้ทำการชำระเงินล่าช้า แต่หากเกิน 7 วันถือว่าเป็นการผิดนัดชำระ

ข้อ 3. การผิดนัดชำระ: หากผู้เช่าซื้อผิดนัดไม่ชำระค่างวดติดต่อกันเกิน 2 งวด ผู้ให้เช่าซื้อมีสิทธิบอกเลิกสัญญา ติดตามยึดสินค้าคืนได้ทันที และสามารถเรียกเก็บค่าเสียหายจากผู้เช่าซื้อได้หากสินค้ามีความเสียหายหรือตำหนิตามกฎหมาย

คู่สัญญาได้อ่านและเข้าใจข้อความโดยละเอียดแล้ว และยินยอมให้ดำเนินการตามกฎหมายหากคู่สัญญาทำผิดตามที่ได้กล่าวไว้ในสัญญา จึงได้ลงลายมือชื่อไว้เป็นหลักฐาน
