เลขที่สัญญา: {{ c.contract_number }}
วันทำสัญญา: {{ c.created_at[:10] if c.created_at else '-' }}

สัญญาฉบับนี้ทำขึ้นระหว่าง ร้านบริการผ่อนสินค้ามือถือ (ซึ่งต่อไปในสัญญานี้จะเรียกว่า "ผู้ให้เช่าซื้อ") ฝ่ายหนึ่ง กับ {{ c.customer_name }} เลขประจำตัวประชาชน {{ c.id_card if c.id_card else '-' }} เบอร์โทรศัพท์ {{ c.phone }} (ซึ่งต่อไปในสัญญานี้จะเรียกว่า "ผู้เช่าซื้อ") อีกฝ่ายหนึ่ง ทั้งสองฝ่ายตกลงทำสัญญากันมีข้อความดังต่อไปนี้:

ข้อ 1. สินค้าเช่าซื้อ: ผู้ให้เช่าซื้อตกลงให้เช่าซื้อ และผู้เช่าซื้อตกลงเช่าซื้อโทรศัพท์มือถือ/สินค้า รุ่น {{ c.product_name }}

ข้อ 2. ราคาสินค้าและการชำระเงิน: ผู้เช่าซื้อตกลงชำระเงินค่าเช่าซื้อเป็นจำนวนเงินรวมทั้งสิ้น ฿{{ "{:,.2f}".format(c.total_amount) }} บาท โดยแบ่งชำระเป็นรายเดือน รวมทั้งสิ้น {{ c.total_installments }} งวด งวดละ ฿{{ "{:,.2f}".format(c.monthly_amount) }} บาท กำหนดชำระทุกวันที่ {{ c.due_day if c.due_day else 5 }} ของทุกเดือน หากผู้เช่าซื้อชำระล่าช้าเกินกำหนด ผู้เช่าซื้อตกลงชำระค่าปรับเป็นจำนวน 100 บาทต่อวัน

ข้อ 3. การผิดนัดชำระ: หากผู้เช่าซื้อผิดนัดไม่ชำระค่างวดติดต่อกันเกิน 2 งวด ผู้ให้เช่าซื้อมีสิทธิบอกเลิกสัญญา และติดตามยึดสินค้าคืนได้ทันที

สัญญาฉบับนี้ทำขึ้นสองฉบับมีข้อความถูกต้องตรงกัน คู่สัญญาได้อ่านและเข้าใจข้อความโดยละเอียดตลอดแล้ว จึงได้ลงลายมือชื่อไว้เป็นหลักฐานต่อหน้าพยาน
